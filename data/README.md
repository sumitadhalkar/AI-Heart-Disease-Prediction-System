# Dataset

This project uses the **UCI Heart Disease Dataset** for educational and research purposes.

## Source

- **Official UCI Machine Learning Repository**: https://archive.ics.uci.edu/ml/datasets/heart+disease
- **Primary data file**: `data/raw/heart.csv` (Cleveland database)
- **Additional databases**: Hungarian, Swiss, and Long Beach VA datasets also available in the UCI repository

## Files

| File | Description |
|---|---|
| `raw/heart.csv` | Cleveland database, 303 instances, 14 attributes (generated by `train_model.py`, default dataset) |
| `raw/heart_combined.csv` | All four UCI sites combined, ~920 instances (generated by `train_model.py --dataset combined`) |
| `raw/heart-disease.names` | Attribute names and descriptions |
| `legacy_uci_archive/` | Raw mirror of the original UCI FTP `heart-disease` directory, kept for reference. `processed.cleveland.data`, `processed.hungarian.data`, `processed.switzerland.data`, and `processed.va.data` are the source files for the combined dataset option below. |

## Attribute Information

The dataset contains 14 attributes (age, sex, cp, trestbps, chol, fbs, restecg, thalach, exang, oldpeak, slope, ca, thal, num), where:

- `num` is the diagnosis target (0 = no disease, 1-4 = presence of disease)
- Target is transformed to binary: 0 vs. (1, 2, 3, 4) for model training

See `heart-disease.names` for full attribute documentation.

## Preprocessing

The `train_model.py` script performs the following:

1. Loads the heart disease dataset (Cleveland via `ucimlrepo` by default, or all four UCI sites via `--dataset combined`)
2. Converts the target from multi-class (0-4) to binary classification (0 = no disease, 1 = disease present)
3. Selects 13 features: age, sex, cp, trestbps, chol, fbs, restecg, thalach, exang, oldpeak, slope, ca, thal
4. Splits data 80/20 train/test with `stratify=y` and `random_state=42`
5. Fits a pipeline with `SimpleImputer(strategy="median")` + `StandardScaler()` + `LogisticRegression(max_iter=2000, class_weight="balanced", random_state=42)`
6. Saves the fitted pipeline to `models/heart_model.joblib`
7. Writes evaluation metrics to `reports/model_evaluation.json` and `reports/model_evaluation.txt`

## Combined Multi-Site Dataset (optional)

Run `python train_model.py --dataset combined` to train on all four original UCI
sites (Cleveland, Hungarian, Switzerland, Long Beach VA — ~920 rows combined)
instead of just the 303-row Cleveland subset. The source files already live in
`legacy_uci_archive/`, so no download is needed for this option.

This saves to `models/heart_model_combined.joblib` and
`reports/model_evaluation_combined.{json,txt}` — separate filenames from the
default run, so it never overwrites the model `app.py` actually serves. The
app always loads `models/heart_model.joblib`; using the combined model would
require pointing `app.py`'s `MODEL_PATH` at it manually.

This dataset is noisier and has far more missing values per feature (especially
`ca` and `thal` outside Cleveland), so held-out accuracy is typically lower than
the Cleveland-only model (~80% vs. ~87%) despite the larger sample size. One
site-specific quirk is handled explicitly: Switzerland's `chol` (serum
cholesterol) column is `0` for every row because that test wasn't performed
there, not because cholesterol was actually zero, so `train_model.py` treats any
`chol == 0` row as missing (imputed like other missing values) rather than as a
real reading.
